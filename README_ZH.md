# 简单自动驾驶沉浸式飞机 — 1.4.0 Alpha

为 Immersive Aircraft 的七种原版飞行器提供独立的自动前进与离地高度辅助。玩家仍负责左右转向；不增加自动寻路，也不修改燃油、动力或服务器物理规则。

## 选择安装包

**只安装一个与你的 Minecraft 版本和加载器相符的 Jar。** 替换旧版插件，不要把整个压缩包内的十个 Jar 全部放进 `mods`。同一 Minecraft 版本的 Fabric 与 Forge / NeoForge 包不能互换。

| Minecraft | Forge / NeoForge | Fabric | Java | 已检查的 Immersive Aircraft |
|---|---|---|---|---|
| 1.20.1 | Forge 47.3.0–47.x | Loader ≥0.16.14；API 0.92.6+1.20.1 | 17+ | 1.5.0 |
| 1.21.1 | NeoForge 21.1.1–21.1.x | Loader ≥0.16.14；API ≥0.116.1，使用 1.21.1 对应包 | 21+ | 1.5.0、1.5.2 |
| 1.21.11 | NeoForge 21.11.45–21.11.x | Loader ≥0.19.5；API ≥0.141.6，使用 1.21.11 对应包 | 21+ | 1.5.0、1.5.2 |
| 26.1.2 | NeoForge 26.1.2.112 起，限对应 26.1.2 分支 | Loader ≥0.19.5；使用 26.1.2 对应 Fabric API | 25+ | 1.5.2 |
| 26.2 | NeoForge 26.2.0.88 起，限对应 26.2 分支 | Loader ≥0.19.5；使用 26.2 对应 Fabric API | 25+ | 1.5.2 |

每个 Jar 的文件名都包含 Minecraft 版本与加载器。例如 `simple-autopilot-immersive-aircraft-1.21.1-neoforge-1.4.0.jar` 用于 Minecraft 1.21.1 NeoForge。你原先的 NeoForge 21.1.243、Immersive Aircraft 1.5.0 在这个包的依赖范围内。

插件安装在客户端即可，服务器不必安装本插件。原版 Immersive Aircraft 及其自身依赖须按原模组要求安装，服务端和客户端的原模组版本应保持兼容。Fabric 实例还需对应 Minecraft 版本的 Fabric API。

## 按键

| 默认按键 | 功能 |
|---|---|
| V | 独立开关自动前进 |
| H | 独立开关离地高度辅助 |
| Page Up | 按设置步长增加目标间距（默认 2 格） |
| Page Down | 按设置步长减少目标间距（默认 2 格） |
| 默认未绑定 | 打开自动驾驶设置：先在游戏按键设置中指定按键 |

默认目标间距 **10 格**，范围 **4–64 格**；测量的是机身底部相对地形的间距，不是世界绝对 Y 坐标。按键可在游戏设置中修改。高度调整与两个开关独立；目标间距、调整步长和面板偏好会跨游戏重启保存，两个自动开关不会保存。Page Up / Down 的步长可在设置页调整为 1–16 格。

其他按键、聊天、菜单或切换窗口不会取消辅助，也不会覆盖已启用的控制轴。关闭相应开关后，该轴恢复手动控制。聊天或菜单内输入 V / H 不会触发新开关。单人游戏自身暂停时，游戏物理仍会暂停。

须坐在驾驶位；支持飞艇、货运飞艇、战斗飞艇、人力飞行器、双翼机、四旋翼和竹制跳跃机。离开驾驶位、死亡、换飞机、换世界或断线会重置开关。固定翼的前进由油门控制、高度由俯仰控制；不能像飞艇一样悬停。

## 1.4.0 新增界面与记忆

坐在支持飞行器的驾驶位时，状态面板会显示自动前进、自动高度和目标间距；高度辅助暂时无法工作时，持续显示动力不足、地形未知、顶棚过近等实际原因。没有近期驾驶数据时显示等待，不把旧数据当作正常状态。面板默认位于左上，可隐藏或放在四个角；F1 隐藏游戏界面时也会隐藏。

**设置页按键默认未绑定。** 在「选项 → 控制 → 按键绑定」的本模组分类中，给「打开自动驾驶设置」指定一个空闲按键；返回游戏并关闭其他菜单后按下即可，不需要先上飞机。

设置页可改目标间距、按键调整步长、面板显示与位置。「保存」才应用修改；「取消」或 Esc 放弃未保存的草稿；「重置」只重置草稿，仍需保存。设置页本身不会暂停游戏。保存失败时，本次会话仍应用所选值，页面明确提示无法保存并可重试。

偏好保存于游戏实例目录下的 `config/aircraft_autoforward.properties`。第一次运行使用默认值；配置无法读取时使用默认值并显示提示，不因此阻止启动。Page Up / Down 调整也会立即保存。换机、下机、死亡或断线仍清除两个自动开关，但保留目标间距。

本版保留 1.3.0 的飞行控制逻辑，不增加绝对 Y 坐标模式、自动转向或路线规划。

## 实验性高度辅助

扫描机身下方、前方地形以及飞行走廊中的方块与顶棚。遇到地形未知、未加载区块、动力不足、迫近障碍或世界高度上限时，暂停相关高度修正并提示；开关保留，条件恢复后继续。不同飞行器按原版控制语义处理减速；固定翼无法通过停止前进来悬停。

**这是 Alpha，不能保证避开所有碰撞。** 不提供路线规划、自动转弯或经验证的自动起降。高速飞行、地形突变和狭小空间仍需玩家介入。

十个安装包已完成真实 Gradle 构建、自动控制测试和依赖字节码 / 安装包检查，共 636 项测试通过。本次未启动或控制 Minecraft；实机加载、面板与设置页显示、飞行手感和多人体验仍需玩家测试。

## 你来测试

1. 使用对应 Jar 替换旧插件并启动。给「打开自动驾驶设置」绑定空闲按键，确认设置页能打开，保存、取消、Esc 和重置草稿正常。
2. 在设置页改目标间距、步长和面板位置，保存后重启游戏，确认这些设置保留。面板只在驾驶位显示，四个角与 F1 隐藏正常。
3. 分别开关 V、H；按其他键、打开聊天和设置页，确认不会被取消；左右仍能手动转向。Page Up / Down 按所选步长调整，范围仍为 4–64。
4. 在测试世界检查未知地形、动力不足或顶棚等暂停提示；恢复条件后应更新，不残留上次原因。先测飞艇，再测固定翼。
5. 下机、换机、死亡、重新连接后检查：两个自动开关重置，目标间距保留。不同 GUI 缩放下确认面板不越过屏幕；多人服仅客户端装插件时再测一次。

若报错，请提供 Minecraft / 加载器 / 原模组版本、所用 Jar 文件名和崩溃报告；若控制表现异常，说明飞行器种类、已开启的开关和复现步骤。

GPL-3.0-only。源码压缩包内每个 Minecraft / 加载器组合都是独立 Gradle 工程，包含对应 Wrapper 和测试；在选定目录运行 `gradlew.bat build --no-daemon --max-workers=2`。Forge 1.20.1 使用 `reobfJar`，Fabric 1.x 使用 `remapJar`；26.x 使用非混淆 Minecraft 工具链，按对应工程的构建配置生成正式 Jar。
